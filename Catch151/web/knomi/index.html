A Pokémon tamagotchi for the BTT Knomi V2. Install it or update it from your browser, with nothing to set up.

1. Plug in your Knomi

  1. Use Chrome or Edge on a computer. Other browsers can't talk to USB devices.
  2. Connect the Knomi V2 with a USB-C data cable. Charge-only cables won't work.

2. Install or update

The same button puts Catch 151 on a new Knomi and updates one that already has it.

This browser can't flash devices. Use Chrome or Edge on a computer. The installer needs an HTTPS page.

Pick the USB serial port when asked, usually named CH340 or wchusbserial. It takes a few minutes, so keep the Knomi plugged in.

Updating? Leave Erase device unticked: your Pokémon, Pokédex and Wi-Fi stay. Ticking it deletes the game and the saved Wi-Fi.

It won't connect, or the install doesn't start? Hold down the Knomi's button (its BOOT button) while you click Install or update and pick the port, and keep holding it until the install starts.

3. Play

Choose your starter: tap the one you want and it's yours. For the clock, swipe down, then swipe left and tap Change Wi-Fi.

Once it's on Wi-Fi, the Knomi installs new versions by itself. You only need this page again to update a Knomi that isn't on Wi-Fi.

This replaces the printer-status firmware on the Knomi. The README explains how to go back, and how to fix a port that doesn't show up.
